# CCAC 基督教會 - 教會應用程式

## 📱 關於
CCAC 教會應用程式，包含前端展示和後端管理系統。

## 🚀 功能特色
- 講道管理 (影片/音頻)
- 文檔上傳與管理
- 活動管理
- 公告管理
- 多語言支援 (繁體中文、簡體中文、英文)
- 管理後台

## 🛠️ 技術架構
- **前端**: HTML + CSS + JavaScript (原生)
- **後端**: Cloudflare Workers
- **資料庫**: Cloudflare D1 (SQLite)
- **儲存**: Cloudflare R2
- **部署**: Cloudflare
