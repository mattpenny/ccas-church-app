1. 登入與登出

  1. 用瀏覽器（手機或電腦皆可）開啟後台網址。
  2. 輸入管理員密碼後按「登入」。密碼由系統管理員設定（Cloudflare 環境變數 ADMIN_PASSWORD）。可按輸入框右邊的 👁 按鈕顯示／隱藏密碼。
  3. 登入狀態會保留在瀏覽器中，下次開啟不必重新輸入。
  4. 離開時（尤其共用電腦）請按右上角「登出」。
💡 建議把後台網址加到書籤／手機主畫面，方便每週更新講道。

2. 認識儀表板

登入後第一頁是儀表板：

  • 統計卡片：講道、文檔、活動、公告的數量。點卡片可直接跳到對應分頁。
  • 快速新增按鈕：🎬 新增講道、📚 新增系列、📄 上傳文檔、📅 新增活動、📢 新增公告。
  • 底部導覽列：講道、系列、文檔、活動、公告 五個分頁，隨時切換。

3. 講道管理

3.1 講道列表（依系列分組）

「🎬 講道」分頁中，講道會依所屬系列分組顯示：

  • 每組預設是收合的，只顯示 ▶ 系列名稱 … N 篇。
  • 點一下組名即可展開／收合該系列的講道清單，避免清單過長。
  • 展開後每篇講道顯示：標題、講員、日期，以及狀態標籤：
標籤意義
🎬 影片 / 🎵 音頻講道類型
▶ YouTube有附 YouTube 影片
🎵 MP3已上傳音頻檔
📄 講義已上傳大綱 PDF
✅ 已發布 / ⛔ 隱藏發布狀態

沒有歸入系列的講道會收在「🎤 單次講道」組。

3.2 新增講道

點「🎬 新增講道」，填寫：

欄位必填說明
標題✅講道名稱，例如「信心的行走」
講員✅例如「陳大衛牧師」
日期✅講道日期
所屬系列—下拉選單；不選 = 歸入「單次講道」
YouTube 影片 ID—例如 nq1e0g8jQpE（可留空）
時長—例如 42:18
類型—🎬 影片 / 🎵 音頻
講道簡介—顯示在播放頁的說明文字
🎵 MP3 音頻檔—按鈕選檔，上限 90MB
📄 講道大綱 PDF—按鈕選檔，上限 20MB
⚠️ 重要規則：YouTube ID 和 MP3 至少要有一個（聽眾總要有東西可看／聽）。只上傳 MP3 時，類型會自動設為「🎵 音頻」。
💡 YouTube ID 取法：影片網址 youtube.com/watch?v= 後面的 11 碼字串。

3.3 編輯講道（含音頻／PDF 上傳）

點任一篇講道的 ✏️ 按鈕：

  • 可修改所有基本欄位（標題、講員、系列、簡介、發布狀態…）。
  • 頁面下方有兩個檔案區塊：

🎵 音頻檔 (MP3)：顯示目前檔名 →「⬆️ 上傳 / 更新 MP3」可新增或替換；已有音頻時可用「🗑️ 移除音頻」。

📄 講道大綱 (PDF)：同上，可新增／替換／移除。

  • 上傳成功後視窗會自動重新整理顯示最新狀態。
  • 記得按「💾 儲存修改」保存基本欄位的變更。

3.4 播放與刪除

  • ▶ 按鈕：直接開啟該講道的 YouTube 影片（僅限有 YouTube ID 的講道）。
  • 🗑️ 按鈕：刪除講道（無法復原；已上傳的音頻/PDF 一併刪除）。

4. 系列管理

系列 = 一組有主題的講道（例如「天地揭秘系列」）。App 中聽眾會先看到系列清單（主標題＋副標題），點進去才看到每篇講道。

4.1 新增系列

點「📚 新增系列」：

欄位必填說明
系列名稱（主標題）✅例如「天地揭秘系列」
副標題—例如「啟示錄逐章查考」，顯示在主標題下方
系列描述—系列內頁頂部的簡介
排序—數字越小排越前（也可之後用 ▲▼ 調整）
🖼️ 封面圖—JPG/PNG/WEBP/GIF，上限 5MB；未上傳時 App 自動用漸層色封面

4.2 調整系列順序（列出優先順序）

「📚 系列」分頁中，每個系列前面有編號（1、2、3…）：

  • 按 ▲ 把該系列上移（在 App 中排更前面）。
  • 按 ▼ 把該系列下移。
  • 排序立即保存，App 中的系列清單會照此順序顯示。

4.3 編輯系列

點 ✏️：可改名稱、副標題、描述、排序、發布狀態，以及「⬆️ 上傳 / 更新封面」替換封面圖。

4.4 刪除系列

點 🗑️ 刪除系列時：

  • 系列下的講道不會被刪除，會自動變回「單次講道」。
  • 封面圖會從雲端儲存移除。
  • 操作無法復原，請確認後再刪。
💡 建議流程：先建立系列 → 再新增講道並選入系列 → 最後用 ▲▼ 排好順序。

5. 文檔管理（週報等）

上傳週報、查經筆記、通訊、照片等，供會眾在 App 的「文檔」頁下載。

點「📄 上傳文檔」：

  • 標題（必填）：例如「週報 2026-09-06」
  • 分類：📋 週報 / 📖 查經筆記 / ✉️ 通訊 / 🖼️ 照片 / 📁 其他
  • 檔案：PDF、JPG、PNG、GIF、WEBP、Word，上限 10MB

列表中每筆文檔可 ⬇️ 下載、✏️ 編輯、🗑️ 刪除。

6. 活動管理

App「活動」頁顯示的教會行事曆項目。

點「📅 新增活動」：

  • 標題 / 日期 / 星期 / 時間 / 地點（皆必填）
  • 選日期後，月曆卡片上的「幾月幾日」會自動帶入
  • 發布狀態：✅ 已發布 / ⛔ 隱藏

列表中可 ✏️ 編輯、🗑️ 刪除。

7. 公告管理

App 首頁頂部的跑馬公告（可附彈窗詳細內容）。

點「📢 新增公告」：

  • 標題（必填）、描述（必填）
  • 時間標籤：例如「2小時前」，留空顯示「剛剛」
  • 彈窗詳細內容：點開公告後顯示的詳細文字（留空則用描述）
  • 發布狀態：✅ 已發布 / ⛔ 隱藏

列表中可 ✏️ 編輯、🗑️ 刪除。

8. 播客 RSS Feed

有上傳 MP3 且已發布的講道會自動進入播客 Feed，不需另外操作：

總 Feed（全部講道）：

https://ccac-api.ccac-church.workers.dev/feed.xml

各系列專屬 Feed（每個系列可當成獨立 Podcast 節目）：

https://ccac-api.ccac-church.workers.dev/feed/series/5.xml

格式：/feed/series/{系列ID}.xml（例如 5 = 哥林多前書系列）
✅ 在 App「講道 → 系列內頁」點「🎙️ 本系列播客 (RSS)」即可一鍵複製該系列的 Feed 網址。

提交到播客平台（每個 Feed 只需提交一次）

1. Apple Podcasts：Podcasts Connect → Apple ID 登入 →「＋」→ 貼上 Feed 網址 → 審核 1–5 個工作天

2. Spotify：Spotify for Creators → 新增節目 → 貼上 Feed 網址

3. 其他平台（iHeartRadio、TuneIn…）同樣貼上此網址即可

💡 若想將不同系列做成不同 Podcast 節目（例如「哥林多前書系列」獨立為一個節目），就把各系列的 Feed 網址分別提交到各平台即可。

注意事項

  • 系列 Feed 的節目名稱與封面取自該系列的名稱與封面圖；總 Feed 則使用後台設定（或系列封面）。
  • 之後每次上傳新講道（有 MP3、已發布），各平台會在數小時內自動抓取。
  • 隱藏（⛔）的講道不會出現在 Feed 中。

9. 常見問題與疑難排解

問題解決方法
Q1：上傳 MP3 到一半失敗？檔案請小於 90MB。若講道已建立但檔案上傳失敗，會出現提示 → 到該講道的「編輯」重新上傳即可。
Q2：上傳後 App 看不到新講道？① 確認「發布狀態」是 ✅ 已發布；② App 下拉重新整理；③ 網頁版按 Ctrl+F5 強制更新。
Q3：PDF 點開是空白或無法檢視？聽眾裝置會用內建 PDF 檢視器開啟；請確認 PDF 未加密、檔案小於 20MB。
Q4：只想讓講道出現在 Feed、不想在 App 出現（或反之）？兩者都以「已發布」為準；若要暫時下架，改為 ⛔ 隱藏即可（Feed 與 App 同步消失）。
Q5：系列刪掉了，講道會不見嗎？不會。講道會自動歸到「單次講道」，可再編輯指派到新的系列。
Q6：排序按了沒反應？請確認網路正常；排序成功會顯示「✅ 排序已更新！」。失敗請重試。

10. 安全注意事項

  • 請勿把密碼告訴不需使用後台的人；密碼更改請聯絡系統管理員（Cloudflare ADMIN_PASSWORD 變數）。
  • 目前登入頁面下方有密碼提示文字（public/admin/index.html 內），正式上線前建議移除該行。
  • 共用電腦使用後，請務必按「登出」。
  • 上傳檔案請使用教會自行拍攝／製作或已授權的內容，避免版權問題。
